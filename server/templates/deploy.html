Windows - many PCs (Group Policy, Intune, RMM)

Paste into an elevated PowerShell to try it on one PC, or use the same script in your management tool. Runs silently, verifies the download, installs the service + watchdog, skips PCs that are already up to date. Log: %ProgramData%\Leakwarden\deploy.log.

Set-ExecutionPolicy -Scope Process Bypass -Force; $f = Join-Path $env:TEMP 'Deploy-Leakwarden.ps1'; Invoke-WebRequest -UseBasicParsing '{{ release_base }}/Deploy-Leakwarden.ps1' -OutFile $f; & $f -ServerUrl '{{ server_url }}' -EnrollmentCode '{{ enroll_code }}'
  1. Intune: Devices → Scripts and remediations → Platform scripts → add Deploy-Leakwarden.ps1 with the parameters in a one-line wrapper; run as system, 64-bit.
  2. Group Policy: Computer Configuration → Policies → Windows Settings → Scripts → Startup → PowerShell Scripts → add the script with -ServerUrl ... -EnrollmentCode ....
  3. No internet on the PCs? Put Leakwarden-windows-x64-{{ version }}.zip on a share and add -PackagePath \\server\share\Leakwarden-windows-x64-{{ version }}.zip -ExpectedSha256 <hash from SHA256SUMS.txt>.

Windows - one PC

Elevated PowerShell, in the agent folder of the extracted release zip:

Set-ExecutionPolicy -Scope Process Bypass -Force; .\install-service.ps1 -ServerUrl '{{ server_url }}' -EnrollmentCode '{{ enroll_code }}' -WithWatchdog

macOS and Linux - one or many machines (Jamf, Kandji, Intune for Mac, SSH, Ansible)

curl -fsSL '{{ release_base }}/deploy-leakwarden.sh' | sudo bash -s -- --server-url '{{ server_url }}' --enrollment-code '{{ enroll_code }}'

macOS: grant /Library/Application Support/Leakwarden/bin/leakwarden-agent Full Disk Access (System Settings → Privacy & Security), or push a PPPC profile from your MDM, so Desktop / Documents / Downloads can be monitored.

After a rollout

  1. Machines appear on the dashboard within a minute, with host name and version.
  2. Rotate the enrollment code (change LEAKWARDEN_ENROLL_CODE and restart) - enrolled machines keep their own tokens.
  3. Lost or retired machine: POST /api/v1/admin/agents/<id>/revoke.
